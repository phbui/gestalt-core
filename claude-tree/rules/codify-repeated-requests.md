# Codify Repeated Requests

**When the user asks for substantially the same thing a second time** (same verb + target shape; check Letta session_patterns for cross-session repeats), **offer one line to codify it** — a skill/rule via /mutate, /capture, or a jarvis timer — then do the requested work either way. Suggest-only, never auto-create; a declined offer is not re-made for that request family. Source: gbrain's "asked twice = you failed" discipline, knowledge/gbrain.md ^thin-harness.
