# Mermaid Diagrams

Use Mermaid fenced code blocks (` ```mermaid `) for diagrams in files — never ASCII art, PlantUML, or images. In terminal output (chat messages), Mermaid doesn't render — use `+--+` ASCII boxes instead. Full box-drawing patterns (flowcharts, decision flows, sequence diagrams): `gestalt/.claude/references/mermaid-diagrams.md`.
