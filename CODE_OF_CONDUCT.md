# Code of conduct

This project is maintained by one person in spare time. The rules are short.

Be direct and be kind. Review the work, not the person. Assume the other person acted in good faith and ask before concluding otherwise. No harassment, no slurs, no personal attacks, no publishing of other people's private information, in issues, pull requests, discussions or anywhere the project is represented.

The maintainer may edit, hide or remove comments that break these rules, and may block an account that keeps breaking them. To report a problem with someone's behaviour in this project, use the private vulnerability reporting form at https://github.com/phbui/gestalt-core/security/advisories/new and mark the report as a conduct matter. It reaches only the maintainer. Reports are answered within 14 days and the reporter's identity is not shared.
